# 2027 수시모집 합불 입력 · PC

Google Sheets `편집` 탭의 지원자 정보를 검색하고 Q:U 결과를 입력하는 PC용 단일 페이지입니다.

- 최초 15건, `더 보기`마다 10건 추가
- 고정 상단 바와 고정 정렬 헤더
- 성명·생년월일·수험번호 복사
- Q:U 다섯 결과 항목을 목록에서 바로 입력하고 자동 저장
- `일괄합산` 1단계 결과는 수정 불가
- 현재 검색 조건의 전체 결과를 원본 A:U 구조의 Excel 파일로 다운로드
- 10초 간격으로 열린 검색 결과 동기화
- 배경 이미지가 `index.html`에 내장됨
- 시트 일괄 갱신 뒤 `publishAdmissionsDataRevision()`을 실행해 열린 화면에 새 데이터 리비전을 즉시 알림

웹 주소: https://seiryu1318.github.io/26early_Ryan/

서버 코드는 `apps-script` 폴더에 있으며, 비밀번호와 세션 서명키는 저장소가 아닌 Apps Script의 스크립트 속성에서 관리합니다.
